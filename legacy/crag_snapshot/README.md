# Read-only CRAG provenance snapshot

These files were copied unchanged from the CRAG repository on 2026-08-25.
They document the earlier MLP/GNN implementations and preliminary results.

Do not import this directory from new experiments. In particular:

- `train_alignment.py` contains a legacy no-gradient GNN path;
- `train_gnn.py` fixes convolution gradients but is not a fully matched study;
- result JSON files are hypothesis-generating, not final paper evidence;
- the HotpotQA result is a deferred marker, not a completed experiment.

The MIT license at the repository root covers the copied source.
